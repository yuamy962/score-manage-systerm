**核心理念**：以贡献衡量价值，以数据支撑绩效。积分代表"贡献价值"，不代表工时。

## 四、普通成员操作指南

### 4.1 查看仪表盘

1. 登录后进入 **仪表盘** 页面（`/dashboard`）
2. 在"我的概览"中可查看：
   - 当月积分汇总
   - 任务完成情况
   - 积分历史趋势图
   - 排名变化趋势图

### 4.2 查看我的任务

1. 进入 **任务管理** 页面（`/dashboard/tasks`）
2. 可查看分配给自己的所有任务及状态
3. 筛选条件：按状态、按月份等

### 4.3 提交任务完成

1. 在任务列表中找到状态为"执行中"的任务
2. 点击任务进入详情
3. 点击"提交完成"按钮
4. 任务状态变为"待审核"，等待项目经理审核

### 4.4 领取任务池任务

1. 在任务管理页面，筛选"任务池"类型的任务
2. 浏览可领取的任务
3. 点击"领取"按钮
4. 等待项目经理确认后，任务变为"待执行"

### 4.5 查看我的积分

1. 进入 **积分管理** 页面（`/dashboard/scores`）
2. 查看个人积分记录，包括：
   - 积分来源（需求开发/运维/团队贡献等）
   - 积分值
   - 生效月份
   - 延期说明（如有）

### 4.6 查看绩效进度

1. 进入 **绩效进度** 页面（`/dashboard/progress`）
2. 查看当前月份的积分进度
3. 查看目标进度可视化（距离下一等级的差距）

### 4.7 提交申诉

1. 进入 **申诉管理** 页面（`/dashboard/appeals`）
2. 找到需要申诉的积分记录
3. 点击"申诉"按钮
4. 填写申诉理由
5. 提交申诉（需在积分生效后 **3个工作日内** 提出）

> ⚠️ 申诉经项目经理复核、部门经理裁定后为最终结果，不可再次申诉。

### 4.8 申请延期

1. 在任务详情中，点击"申请延期"
2. 填写延期原因和预计完成时间
3. 提交后等待项目经理审批
4. 审批通过的延期 **不扣罚** 积分

### 4.9 查看成就徽章

1. 进入 **成就徽章** 页面（`/dashboard/badges`）
2. 查看已解锁和未解锁的徽章
3. 了解解锁条件

## 五、项目经理操作指南

### 5.1 创建任务

1. 进入 **任务管理** 页面（`/dashboard/tasks`）
2. 点击"新建任务"按钮
3. 填写任务信息：
   - 任务标题
   - 任务描述
   - 预估工作量（人日）
   - 任务类型（需求开发/测试联调/运维支撑等）
   - 任务来源（自研/非自研）
   - 计划完成时间
   - 是否为任务池任务
4. 如为测试联调类任务，需设置权重分配：
   - 开发 40% / 测试 25% / 联调 20% / 上线 10% / 文档 5%
5. 提交创建

### 5.2 分配任务

1. 在任务列表中找到"待执行"的任务
2. 点击"分配人员"
3. 选择负责人，设置贡献比例（ratio）
4. 确认分配

### 5.3 审核任务

1. 在任务列表中筛选"待审核"的任务
2. 查看成员提交的完成情况
3. 操作选择：
   - **通过**：任务变为"已完成"，系统自动计算积分
   - **驳回**：任务变为"已驳回"，需成员重新执行

### 5.4 积分自动计算规则

任务审核通过后，系统自动按以下公式计算积分：

```
个人积分 = 最终工作量(人日) × 贡献比例 × 积分转换比例
```

- **自研项目**：积分转换比例 = 1.0
- **非自研项目**：积分转换比例 = 0.6

### 5.5 录入运维积分

1. 成员提交运维申请后，在积分管理页面审核
2. 根据运维级别确定积分范围：
   - P3 级：1~3 分
   - P2 级：3~8 分
   - P1 级：10~30 分（需部门经理终审）
3. 注意加成系数：
   - 夜间处理：×1.5
   - 节假日处理：×1.5
   - 夜间+节假日：×1.8

### 5.6 审核团队贡献积分

1. 成员提交团队贡献申请
2. 项目经理初审通过后，提交至部门经理终审
3. 团队贡献类型包括：文档编写、知识分享、带教新人、自动化优化

### 5.7 生成与下发绩效评语

1. 进入 **绩效评语** 页面（`/dashboard/reviews`）
2. 选择月份，点击"生成评语"（生成草稿状态）
3. 编辑评语内容
4. 确认无误后点击"下发"
5. **注意**：下发后评语不可再修改

### 5.8 审批延期申请

1. 进入 **延期申请** 页面（`/dashboard/extensions`）
2. 查看成员提交的延期申请
3. 审批操作：
   - **通过**：延期不扣罚积分
   - **驳回**：按延期天数扣罚积分

### 5.9 创建任务池任务

1. 创建任务时，勾选"任务池任务"
2. 任务创建后状态为"任务池(POOL)"
3. 成员领取后，状态变为"待确认(CLAIMED)"
4. 项目经理确认后，任务进入正常流程

### 5.10 查看成员总览与任务总览

1. 在仪表盘页面切换至"成员总览"选项卡
   - 查看团队成员积分排名
   - 查看任务完成情况
2. 切换至"任务总览"选项卡
   - 查看所有任务状态分布
   - 查看任务进度

## 六、部门经理操作指南

### 6.1 查看全局数据

1. 登录后进入仪表盘
2. 可查看所有成员的积分数据、任务数据
3. 切换"成员总览"和"任务总览"选项卡获取全局视角

### 6.2 审核特殊加减分

1. P1 级运维积分需部门经理终审
2. 团队贡献积分需部门经理终审
3. 客户反馈积分（表扬 +2~+10，投诉 -5~-20）
4. 风险扣减积分：
   - 低级错误：-3 分
   - 未按流程：-5 分
   - 严重返工：-10 分
   - 重大事故：-20~-50 分

### 6.3 配置绩效阈值

1. 进入系统配置
2. 调整绩效等级对应的积分阈值
3. 默认阈值：

| 当月积分 | 等级 |
|----------|------|
| ≥180 | A（卓越） |
| ≥135 | B+（优秀） |
| ≥115 | B（达标） |
| ≥77 | C（待改进） |
| <77 | D（不达标） |

> 同分排名规则：任务完成数多者优先，并列时跳号处理。

### 6.4 用户管理

1. 进入 **用户管理** 页面（`/dashboard/users`，仅部门经理可见）
2. 可执行操作：
   - 新增用户
   - 修改用户角色（MEMBER / PM / MANAGER）
   - 重置用户密码
   - 修改用户手机号
   - 禁用/启用用户

### 6.5 申诉裁定

1. 成员申诉经项目经理复核后，提交至部门经理
2. 部门经理查看申诉详情和项目经理意见
3. 做出最终裁定（不可再次申诉）

## 七、积分体系说明

### 7.1 积分类型

| 积分类型 | 说明 | 计算方式 |
|----------|------|----------|
| 需求开发 | 标准工作量即基础积分 | 工作量 × 贡献比例 × 转换比例 |
| 测试联调 | 按权重拆分积分 | 开发40%/测试25%/联调20%/上线10%/文档5% |
| 运维支撑 | 按级别给分 | P3(1~3分)/P2(3~8分)/P1(10~30分) |
| 团队贡献 | 文档/分享/带教/自动化优化 | 由项目经理初审、部门经理终审 |
| 客户反馈 | 表扬或投诉 | 表扬+2~+10，投诉-5~-20 |
| 风险扣减 | 质量问题扣分 | 低级错误-3/未按流程-5/严重返工-10/重大事故-20~-50 |

### 7.2 运维积分加成

| 场景 | 加成系数 |
|------|----------|
| 正常工作时间 | ×1.0 |
| 夜间处理 | ×1.5 |
| 节假日处理 | ×1.5 |
| 夜间+节假日 | ×1.8 |

### 7.3 积分转换比例

| 任务来源 | 转换比例 |
|----------|----------|
| 自研 | 1.0 |
| 非自研 | 0.6 |

### 7.4 积分生效月份

积分的 effectMonth 取 **审核通过时间所在月份**，即当月审核通过的任务积分计入当月绩效。

## 八、绩效等级与评估

### 8.1 绩效等级

| 等级 | 名称 | 当月积分要求 |
|------|------|-------------|
| A | 卓越 | ≥180 |
| B+ | 优秀 | ≥135 |
| B | 达标 | ≥115 |
| C | 待改进 | ≥77 |
| D | 不达标 | <77 |

### 8.2 排名规则

- 按当月总积分降序排列
- 同分时，任务完成数多者优先
- 并列排名时跳号（如两人并列第3，下一名为第5）

### 8.3 绩效评语

- 项目经理可按月生成绩效评语（草稿状态）
- 编辑确认后下发，下发后不可修改
- 成员可在绩效评语页面查看已下发的评语

## 九、任务状态流转说明

### 9.1 标准流程

```
草稿(DRAFT) → 待执行(PENDING) → 执行中(IN_PROGRESS) → 待审核(IN_REVIEW) → 已完成(COMPLETED)
```

### 9.2 驳回流程

```
待审核(IN_REVIEW) → 已驳回(REJECTED) → 执行中(IN_PROGRESS)（重新执行）
```

### 9.3 任务池流程

```
任务池(POOL) → 待确认(CLAIMED) → 待执行(PENDING) → （进入标准流程）
```

### 9.4 取消

```
任何未完成状态 → 已取消(CANCELLED)
```

> ⚠️ 已完成的任务不可取消，已完成任务的积分不可回撤。

## 十、延期扣罚机制

### 10.1 扣罚公式

```
最终积分 = 基础积分 × 0.9^延期天数
```

最低保留基础积分的 **30%**。

### 10.2 示例

| 延期天数 | 计算系数 | 最终积分（基础10分为例） |
|----------|----------|------------------------|
| 0天 | 1.0 | 10.0 |
| 1天 | 0.9 | 9.0 |
| 2天 | 0.81 | 8.1 |
| 3天 | 0.729 | 7.29 |
| 5天 | 0.59049 | 5.9 |
| 10天 | 0.34868 | 3.49（≥30%，正常扣罚） |
| 13天 | 0.25419 | 3.0（已触底30%下限） |

### 10.3 延期豁免

- 成员可申请延期，经项目经理审批通过后不扣罚
- 审批通过的延期需记录延期原因和新的预计完成时间

## 十二、常见问题

### Q1：忘记密码怎么办？
联系部门经理在用户管理页面重置密码，重置后首次登录需修改密码。

### Q2：积分什么时候生效？
积分在任务审核通过时自动计算并生效，effectMonth 为审核通过时间所在月份。

### Q3：已完成的任务积分可以撤销吗？
不可以。已完成的任务积分不可回撤。

### Q4：申诉有时效限制吗？
有。需在积分生效后 **3个工作日内** 提出申诉，逾期不再受理。

### Q5：对申诉结果不满意怎么办？
部门经理的裁定为最终结果，不可再次申诉。

### Q6：非自研项目的积分为什么低？
非自研项目的积分转换比例为 0.6（自研为 1.0），这是系统设计规则，体现自研贡献的更高价值。

### Q7：任务池任务如何领取？
在任务管理页面筛选"任务池"类型的任务，点击"领取"后等待项目经理确认即可。

### Q8：绩效评语下发后还能修改吗？
不能。评语一旦下发即锁定，不可再修改。

### Q9：延期扣罚最低扣到多少？
最低保留基础积分的 30%，不会扣到零。

### Q10：企微通知收不到怎么办？
确认企微群机器人 Webhook 配置正确，联系管理员检查通知服务状态。
