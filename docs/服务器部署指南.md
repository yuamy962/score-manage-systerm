## 第三步：安装 Node.js（JavaScript 运行环境）

我们的系统是用 Node.js 写的，需要安装它。这里安装 Node.js 18 LTS（长期支持版）：

```bash
# 添加 Node.js 官方源
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -

# 安装 Node.js（会自动带上 npm）
sudo apt install -y nodejs

# 验证安装是否成功
node -v
npm -v
```

> ✅ 如果 `node -v` 显示 `v18.x.x`，`npm -v` 显示 `9.x.x` 或 `10.x.x`，就说明安装成功了。

## 第四步：安装 PostgreSQL 数据库

### 4.1 安装 PostgreSQL

```bash
sudo apt install -y postgresql postgresql-contrib
```

### 4.2 启动数据库并设置开机自启

```bash
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 4.3 验证数据库是否运行

```bash
sudo systemctl status postgresql
```

> ✅ 看到 `active (exited)` 或 `active (running)` 就是正常的。按 `q` 退出查看。

### 4.4 创建数据库用户和数据库

```bash
# 切换到 postgres 用户（PostgreSQL 的管理员）
sudo -u postgres psql
```

进入数据库命令行后（前面会变成 `postgres=#`），依次执行以下 3 条命令：

```sql
-- 创建数据库用户（把 QH_bss_0971 换成你想要的密码，记住它！）
CREATE USER scoreuser WITH PASSWORD 'QH_bss_0971';

-- 创建数据库
CREATE DATABASE scoremanage OWNER scoreuser;

-- 给用户授权
GRANT ALL PRIVILEGES ON DATABASE scoremanage TO scoreuser;

-- 退出
\q
```

> ⚠️ 注意：每条 SQL 命令末尾要有分号 `;`，没有分号不会执行！
>
> 💡 密码 `QH_bss_0971` 要和后面配置文件里的一致。

### 4.5 验证数据库能否连接

```bash
psql -U scoreuser -d scoremanage -h localhost -W
```

- 提示输入密码时输入 `QH_bss_0971`
- 如果进入 `scoremanage=>` 提示符，说明连接成功
- 输入 `\q` 退出

> ❌ 如果提示 `psql: error: connection to server...`，执行以下修复：
> ```bash
> sudo -u postgres psql -c "ALTER USER scoreuser WITH LOGIN;"
> ```
> 然后重试连接。

## 第九步：配置前端生产环境的 API 代理

前端需要知道后端 API 的地址。在生产环境中，我们用 Nginx 做反向代理，所以前端直接请求同域名的 `/api` 路径即可。

编辑前端的 next.config.js：

```bash
cd /home/ubuntu/score-manage-systerm/frontend
nano next.config.js
```

确认内容如下（默认应该已经是这样）：

```js
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactStrictMode: true,
  async rewrites() {
    return [
      {
        source: '/api/:path*',
        destination: 'http://localhost:3001/:path*',
      },
    ];
  },
};

module.exports = nextConfig;
```

保存退出（`Ctrl+O` → `Enter` → `Ctrl+X`）。

## 第十步：用 PM2 启动服务

### 10.1 创建 PM2 配置文件

```bash
cd /home/ubuntu/score-manage-systerm
nano ecosystem.config.js
```

粘贴以下内容：

```js

  apps: [
    {
      name: 'score-backend',
      cwd: '/home/ubuntu/score-manage-systerm/backend',
      script: 'dist/main.js',
      env: {
        NODE_ENV: 'production',
        PORT: 3001,
      },
    },
    {
      name: 'score-frontend',
      cwd: '/home/ubuntu/score-manage-systerm/frontend',
      script: 'node_modules/.bin/next',
      args: 'start -p 3000',
      env: {
        NODE_ENV: 'production',
        PORT: 3000,
      },
    },
  ],
};
```

保存退出。

### 10.2 启动服务

```bash
cd /home/ubuntu/score-manage-systerm
pm2 start ecosystem.config.js
```

> ✅ 应该看到两个应用都是 `online` 状态。

### 10.3 设置 PM2 开机自启

```bash
pm2 save
pm2 startup
```

> ⚠️ `pm2 startup` 会输出一条以 `sudo` 开头的命令，把那条命令复制执行一下！

### 10.4 常用 PM2 命令

```bash
pm2 list              # 查看所有应用状态
pm2 logs              # 查看实时日志
pm2 logs score-backend # 只看后端日志
pm2 logs score-frontend # 只看前端日志
pm2 restart all       # 重启所有应用
pm2 restart score-backend  # 只重启后端
pm2 stop all          # 停止所有应用
pm2 delete all        # 删除所有应用
```

## 第十一步：安装 Nginx（反向代理，让外网能访问）

### 11.1 安装 Nginx

```bash
sudo apt install -y nginx
```

### 11.2 创建 Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/score-manage
```

粘贴以下内容：

```nginx
server {
    listen 80;
    server_name 124.220.134.186;

    # 前端页面
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_cache_bypass $http_upgrade;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://localhost:3001/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_cache_bypass $http_upgrade;
    }
}
```

保存退出。

### 11.3 启用配置

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/score-manage /etc/nginx/sites-enabled/

# 删除默认配置（避免冲突）
sudo rm -f /etc/nginx/sites-enabled/default

# 测试配置是否正确
sudo nginx -t
```

> ✅ 看到 `syntax is ok` 和 `test is successful` 就没问题。

### 11.4 启动 Nginx

```bash
sudo systemctl restart nginx
sudo systemctl enable nginx
```

腾讯云轻量服务器需要在**两个地方**开放端口：

### 12.2 腾讯云控制台安全组

1. 登录 [腾讯云轻量服务器控制台](https://console.cloud.tencent.com/lighthouse)
2. 点击你的服务器实例
3. 点击「防火墙」标签
4. 点击「添加规则」
5. 添加以下规则：
   - 协议：TCP，端口：80，策略：允许
   - 协议：TCP，端口：443，策略：允许

## ❓ 常见问题排查

### 1. 浏览器打不开页面

```bash
# 检查 PM2 应用是否在线
pm2 list

# 检查 Nginx 是否运行
sudo systemctl status nginx

# 检查端口是否监听
sudo ss -tlnp | grep -E '80|3000|3001'
```

### 2. 后端报数据库连接失败

```bash
# 检查 PostgreSQL 是否运行
sudo systemctl status postgresql

# 测试数据库连接
psql -U scoreuser -d scoremanage -h localhost -W

# 检查 .env 文件中的 DATABASE_URL 是否正确
cat /home/ubuntu/score-manage-systerm/backend/.env
```

### 3. 前端页面空白或 502

```bash
# 查看后端日志
pm2 logs score-backend --lines 50

# 查看前端日志
pm2 logs score-frontend --lines 50

# 查看后端是否在 3001 端口运行
curl http://localhost:3001
```

### 4. 权限问题

```bash
# 确保项目目录属于 ubuntu 用户
sudo chown -R ubuntu:ubuntu /home/ubuntu/score-manage-systerm
```

### 5. 修改了 .env 后需要重启

```bash
pm2 restart score-backend
```
