# 部门积分绩效管理系统 — 汇报材料

> 一句话：用 AI 自主开发的绩效管理工具，零采购成本，让部门绩效评估从"凭印象"变成"看数据"。

---

## 一、解决了什么问题

| 以前 | 现在 |
|------|------|
| 月底说不清每人干了多少活 | 全部工作自动折算积分，实时可见 |
| 绩效打分凭主管记忆，员工不服 | 系统按月自动生成等级和排名，数据说话 |
| 文档、带教、夜间救火等贡献被埋没 | 六类工作统一量化，隐性贡献看得见 |
| 绩效争议多、解释成本高 | 全程留痕+申诉通道，结果服众 |

---

## 二、系统怎么运转

```
PM建任务 → 成员执行提交 → PM审核 → 系统自动算积分
→ 月度汇总生成绩效等级(A~D)与排名 → 经理下发评语 → 员工可申诉
```

覆盖部门全部六类工作：需求开发、测试联调、运维支撑、团队贡献、客户反馈、风险扣减。

---

## 三、价值与亮点

| 维度 | 说明 |
|------|------|
| **零成本** | 无采购、无外包，本人利用 AI 辅助编程自主开发部署 |
| **AI 提效实践** | 公司倡导"全员 AI 提效"，本系统是可直接展示的落地案例 |
| **管理降本** | 绩效统计零人工，月度报告自动生成，争议显著减少 |
| **激励显性化** | 排行榜、徽章、周度之星，让比贡献成为部门风气 |

---

## 四、推广建议

系统基于通用积分模型构建，规则、阈值均可配置，具备向其他部门/条线推广的条件。建议：

1. 以本部门为试点运行一个完整考核周期，沉淀方法论
2. 输出"AI 辅助开发 + 部门自运营"的降本模式，供全司参考
