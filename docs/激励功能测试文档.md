## 一、排行榜增强（制造紧迫感）

## 三、成就体系（游戏化激励）

### 3.1 成就徽章页面

**测试步骤：**
1. 点击左侧菜单「成就徽章」

**预期结果：**
- 顶部显示成就进度条（已解锁 X/9）
- 9个徽章卡片展示：
  - 🌟 月度之星
  - 💎 连续3个月A级
  - 🌾 任务收割机
  - 🛡️ 零驳回
  - 📚 知识贡献者
  - 🏅 百积分里程碑
  - 🥈 五百积分里程碑
  - 🥇 千积分里程碑
  - 🔥 稳定输出
- 已解锁徽章：彩色显示 + "✓ 已解锁"标签 + 获得时间 + 获得原因
- 未解锁徽章：灰色半透明 + "尚未解锁"

### 3.2 月度之星徽章

**测试步骤：**
1. 确认某月积分排名第1名的用户
2. 以该用户身份审批一条积分记录
3. 查看该用户的成就徽章页面

**预期结果：**
- 该用户获得"月度之星"徽章
- 企微群收到"🏅 成就解锁！"通知

### 3.3 任务收割机徽章

**测试步骤：**
1. 为某用户当月录入≥10条带任务的积分记录并审批
2. 再次审批一条积分触发徽章检查
3. 查看该用户的成就徽章页面

**预期结果：**
- 该用户获得"任务收割机"徽章

### 3.4 零驳回徽章

**测试步骤：**
1. 确认某用户当月无被驳回的任务
2. 审批一条积分触发徽章检查
3. 查看该用户的成就徽章页面

**预期结果：**
- 该用户获得"零驳回"徽章

### 3.5 知识贡献者徽章

**测试步骤：**
1. 为某用户录入一条类型为"团队贡献"的积分记录并审批
2. 再次审批一条积分触发徽章检查
3. 查看该用户的成就徽章页面

**预期结果：**
- 该用户获得"知识贡献者"徽章

### 3.6 里程碑徽章

**测试步骤：**
1. 确认某用户累计积分达到100/500/1000分
2. 审批一条积分触发检查
3. 查看该用户的成就徽章页面

**预期结果：**
- 达到100分：获得"百积分里程碑"徽章，企微群收到"🎉 里程碑达成！"通知
- 达到500分：获得"五百积分里程碑"徽章
- 达到1000分：获得"千积分里程碑"徽章

### 3.7 连续达标徽章

**测试步骤：**
1. 确认某用户连续3个月绩效等级达到A
2. 审批一条积分触发检查
3. 查看该用户的成就徽章页面

**预期结果：**
- 连续3个月A级：获得"连续3个月A级"徽章
- 连续3个月B+以上：获得"稳定输出"徽章

## 五、数据驱动

### 5.1 同角色对比

**测试步骤：**
1. 进入「我的进度」页面
2. 查看底部同角色对比表

**预期结果：**
- 仅显示与当前用户同角色的成员
- 包含排名、姓名、积分、绩效等级
- 当前用户行高亮

### 5.2 月末冲刺提醒

**测试步骤：**
1. 等待每月28-31日早上9点（Cron: `0 9 28-31 * *`）
2. 确认有用户距上一等级差距≤20分

**预期结果：**
- 企微群收到"🔥 月末冲刺提醒"消息
- 包含距本月结束剩余天数
- 列出距上一等级仅差一步的用户及差距分数

### 5.3 积分预测

**测试步骤：**
1. 进入「我的进度」页面
2. 查看积分预测区域

**预期结果：**
- 日均积分 = 当月总积分 / 已过天数
- 预测月末积分 = 日均积分 × 月总天数
- 月末≤5天时显示冲刺提醒

## 八、定时任务汇总

| 任务 | Cron 表达式 | 触发时间 | 说明 |
|------|------------|---------|------|
| 即将到期任务提醒 | `0 10 * * *` | 每天10:00 | 提醒2天内到期任务 |
| 周度之星推送 | `30 17 * * 5` | 每周五17:30 | 推送本周积分之星 |
| 月末冲刺提醒 | `0 9 28-31 * *` | 每月28-31日9:00 | 提醒距等级差距≤20分的用户 |

## 九、数据库变更

新增 `badges` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (cuid) | 主键 |
| userId | String | 用户ID |
| type | BadgeType (enum) | 徽章类型 |
| reason | String | 获得原因 |
| month | String? | 获得月份（月度徽章使用） |
| createdAt | DateTime | 创建时间 |

唯一约束：`(userId, type, month)`

新增 `BadgeType` 枚举：
- MONTHLY_STAR
- CONSECUTIVE_A_GRADE
- TASK_HARVESTER
- ZERO_REJECTION
- KNOWLEDGE_CONTRIBUTOR
- MILESTONE_100
- MILESTONE_500
- MILESTONE_1000
- CONSECUTIVE_BP
